# Soal UTS (Pertemuan 1-4) - 20 Soal Pilihan Ganda

Pilih satu jawaban yang paling benar!

**1.** CSS adalah singkatan dari ...
A. Computer Style Sheets
B. Cascading Style Sheets
C. Creative Style System
D. Colorful Style Sheets

**2.** Fungsi CSS pada sebuah website adalah ...
A. Membuat struktur halaman
B. Menyimpan data pengunjung
C. Membuat database
D. Memberi gaya tampilan

**3.** Jika HTML diibaratkan kerangka rumah, maka CSS diibaratkan ...
A. Pondasi
B. Atap
C. Cat dan dekorasi
D. Pintu

**4.** Tiga bagian dalam aturan CSS adalah ...
A. Selector, property, dan value
B. Judul, paragraf, dan gambar
C. Head, body, dan footer
D. Tag, atribut, dan isi

**5.** Penulisan aturan CSS yang benar adalah ...
A. h1 (color=blue)
B. h1 [color: blue]
C. `<h1 color:blue>`
D. h1 { color: blue; }

**6.** Setiap property CSS diakhiri dengan tanda ...
A. Titik (.)
B. Koma (,)
C. Titik koma (;)
D. Titik dua (:)

**7.** CSS yang ditulis langsung pada atribut `style` di tag HTML disebut ...
A. Inline CSS
B. Internal CSS
C. External CSS
D. Dynamic CSS

**8.** Internal CSS ditulis di dalam tag ... pada bagian `<head>`.
A. `<css>`
B. `<style>`
C. `<link>`
D. `<script>`

**9.** Cara menambahkan CSS yang paling disarankan adalah ...
A. Inline CSS
B. Internal CSS
C. Semua cara sama saja
D. External CSS

**10.** Tag yang dipakai untuk menghubungkan file CSS ke HTML adalah ...
A. `<link>`
B. `<style>`
C. `<css>`
D. `<a>`

**11.** Komentar di dalam CSS ditulis dengan ...
A. `<!-- komentar -->`
B. `// komentar`
C. `/* komentar */`
D. `# komentar`

**12.** Selector yang memilih elemen berdasarkan id diawali dengan tanda ...
A. Titik (.)
B. Pagar (#)
C. Bintang (*)
D. Koma (,)

**13.** Selector yang memilih elemen berdasarkan class diawali dengan tanda ...
A. Titik (.)
B. Pagar (#)
C. Bintang (*)
D. Koma (,)

**14.** Property untuk mengubah warna teks adalah ...
A. text-color
B. font-color
C. background
D. color

**15.** Property untuk mengubah warna latar belakang adalah ...
A. bg-color
B. color-back
C. background-color
D. back-color

**16.** Agar teks berada di tengah, kita menulis ...
A. text-style: center;
B. text-align: center;
C. align-text: middle;
D. font-align: center;

**17.** Kode `text-decoration: underline;` berfungsi untuk ...
A. Membuat teks tebal
B. Membuat teks miring
C. Membuat teks besar
D. Memberi garis bawah pada teks

**18.** Agar sebuah kotak berbentuk lingkaran (lebar dan tinggi sama), nilai border-radius yang dipakai adalah ...
A. 0
B. 5px
C. 50%
D. 100px

**19.** Pada kode `border: 2px solid red;`, kata "solid" berarti ...
A. Garis biasa yang menyambung
B. Garis putus-putus
C. Garis titik-titik
D. Garis ganda

**20.** Property untuk membuat garis tepi hanya di bagian bawah elemen adalah ...
A. border-under
B. bottom-line
C. border-low
D. border-bottom
